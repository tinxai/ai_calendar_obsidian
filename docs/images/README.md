# README illustrations

These diagrams contain fictional sample events and plans. They illustrate the plugin layout and planning workflow; they are not screenshots of a user's vault. The AI response shown is an example.

- `calendar-overview.svg`: editable vector source for the calendar, inline editor, and assistant overview.
- `planning-workflow.svg`: editable vector source for the connected planner and sample weekly review.
- Matching PNG files are used in the root README for compatibility with Markdown viewers.

Export the SVGs with librsvg when updating them:

```sh
rsvg-convert docs/images/calendar-overview.svg -o docs/images/calendar-overview.png
rsvg-convert docs/images/planning-workflow.svg -o docs/images/planning-workflow.png
```
